# Changelog

## 1.0.0

First public release of GrocerEase, an on-device grocery list manager.

### Added

- Nested items with notes. Checking an item adds it and its child items to the shopping list. Swipe right to add a note, or swipe left to delete an item and its children.
- A shopping list of those checked items, plus one-time items that are removed when completed.
- Optional history, so a completed item can be restored, and a control to clear that history.
- Sorting by creation order, a custom order, or name.
- Search by item name.
- A setting to wrap long names and notes onto more than one line.
- Copy the current shopping list, or copy and restore the items list as text.
